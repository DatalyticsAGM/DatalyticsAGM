Modelo datos, escribo SQL y construyo cuadros de mando para que las decisiones
de negocio se tomen con evidencia y no con intuición. Trabajo con KPIs,
márgenes, control presupuestario y automatización de reporting en banca,
telecomunicaciones e industria.

Lo que más me interesa de un análisis es que se sostenga: que las tablas estén
bien unidas, que la métrica mida lo que dice medir y que las limitaciones estén
escritas en el informe.
